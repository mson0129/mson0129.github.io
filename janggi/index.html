Jang-gi V1.0 · 1991 · 이학종원본 DOS판

새 대국

초가 먼저 둡니다. 원본 파일의 기물 배치를 사용합니다.

조작법

내 기물을 터치하거나 클릭한 뒤, 표시된 이동 위치를 선택하세요.

키보드는 방향키로 교차점을 이동하고 Enter 또는 Space로 선택·착수합니다. Esc는 선택 취소입니다.

무르기는 컴퓨터의 응수까지 되돌립니다. 한 수 쉼은 장군 상태가 아닐 때 사용할 수 있습니다. 대국은 이 기기에 자동 저장됩니다.

포팅 정보

Rust로 작성한 장기 엔진을 WASM으로 빌드했습니다. 컴퓨터의 평가식과 난수 처리를 기존 C 엔진과 비교해 복원했습니다.

DOS 에뮬레이터 없이 실행합니다. 메뉴·입력·저장은 웹용으로 구성했습니다. 원본의 인쇄, 기보 파일 재생, 설정 편집 화면은 포함하지 않았습니다.
